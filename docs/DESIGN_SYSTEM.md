# 湾谷运营工作台 · 设计系统 v1

> 风格关键词：**浅色 · 克制 · 高信息密度 · 数据为主角**。界面本身保持安静，颜色只用来表达状态和数据。
> 落地位置：`web/src/styles/index.css`（CSS 变量 + Tailwind v4 `@theme`），组件在 `web/src/components/ui/`。

## 1. 设计原则

1. **楼栋是统一抓手**。所有模块都能按楼栋筛选，楼栋编号（`3#`）在全站写法一致，点击任意楼栋都会跳到全景页。
2. **颜色只表达状态**。红、黄、绿只用于超时、风险和健康度，而且一定配图标和文字；业务域强调色只出现在导航和页头。
3. **先结论，后明细**。每页从上到下依次是：KPI 行 → 主图表 → 明细表或看板。
4. **刷新时不跳动**。重新取数时保留上一帧，半透明显示，不出现闪烁和布局抖动。

### 2.3 状态色（专用，不得用作系列色）

| 语义 | 实色 | 浅底 | 文字 | 场景 |
|---|---|---|---|---|
| critical / 红 | `#d03b3b` | `#fdeeee` | `#b42323` | 红色超时、高危、bad |
| warning / 黄 | `#e9a100` | `#fff6e0` | `#9a6400` | 黄色超时、中危、warn |
| good / 绿 | `#0ca30c` | `#e8f7e8` | `#0b7a0b` | 正常、已完成、good |
| info / 蓝 | `#2563eb` | `#eaf1fe` | `#1d4ed8` | 跟进中 |
| neutral | `#8a94a6` | `#f1f4f8` | `#4a5568` | 待定、其他 |

规则：状态徽章必须带图标或圆点，再加中文文字。浅底配深文字，保证对比度 ≥ 4.5:1。

### 2.4 图表配色（已用 dataviz validator 对 `#ffffff` 校验通过）

- **分类色**（固定顺序，不循环）：`#2a78d6` 蓝、`#eb6834` 橙、`#1baf7a` 青绿、`#eda100` 黄、`#e87ba4` 品红、`#008300` 绿、`#6250d6` 紫、`#e34948` 红
  - 相邻色对 CVD ΔE 最小 9.1，正常视觉 ΔE 最小 19.6，全部 PASS。青绿、黄、品红与白底的对比度不足 3:1，所以凡用到这三色的图表必须附直接标签或数据表。
- **顺序色**（热力图）：蓝色单色阶 `#eef5fd → #cde2fb → #86b6ef → #3987e5 → #1c5cab → #0d366b`。
- **单系列**统一用 `--domain-*` 的实色；对比用的「上期」或「基线」用 `--ink-4` 灰。
- 图表尺寸规范：线宽 2px，柱宽 ≤ 24px，柱端 4px 圆角，网格线 1px 实线 `--grid`，坐标轴文字 `--ink-3` 12px。
- 两个及以上系列必须显示图例；数值标签只标关键点（端点、极值）。所有图表都有 hover tooltip，tooltip 里数值在前、名称在后。

### 2.5 字体与数字

```
--font-sans: "Inter var", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "SF Mono", ui-monospace, Menlo, Consolas, monospace;
```

| 级别 | 大小 / 行高 / 字重 | 用途 |
|---|---|---|
| display | 32 / 38 / 600 | 首页主数字（每页最多一个） |
| kpi | 26 / 32 / 600 | KPI 卡数值 |
| h1 | 20 / 28 / 600 | 页面标题 |
| h2 | 15 / 22 / 600 | 卡片标题 |
| body | 13 / 20 / 400 | 正文、表格 |
| caption | 12 / 16 / 400 | 辅助说明、坐标轴 |
| micro | 11 / 14 / 500 | 徽章、标签 |

- 表格中的数字列、坐标轴、编号使用 `tabular-nums`。KPI 大数字使用比例数字。
- 数值格式：超过 1 万显示为「4.17 万」，kWh 保留整数并加千分位，百分比保留 1 位小数。

### 2.6 间距、圆角、阴影、动效

- 间距按 4px 栅格：4 / 8 / 12 / 16 / 20 / 24 / 32。卡片内边距 16–20px，卡片间距 16px。
- 圆角：`--radius-sm 6px`（徽章、输入框）、`--radius 10px`（按钮、卡片内块）、`--radius-lg 14px`（卡片、抽屉）。
- 阴影：
  - `--shadow-card: 0 1px 2px rgba(15,23,41,.04), 0 1px 1px rgba(15,23,41,.02)`
  - `--shadow-pop: 0 12px 32px -8px rgba(15,23,41,.18), 0 4px 8px -4px rgba(15,23,41,.08)`
  - `--shadow-drawer: -16px 0 48px -12px rgba(15,23,41,.22)`
- 动效：`--ease: cubic-bezier(.2,.7,.2,1)`；悬停 120ms，抽屉和弹层 220ms。遵守 `prefers-reduced-motion`。

## 3. 组件规范

| 组件 | 规范要点 |
|---|---|
| **Sidebar** | 宽 232px，可折叠到 64px，深色 `--nav-bg`。分组为「总览 / 能耗 / 维修 / 攻坚 / 全景」。激活项左侧有 3px 业务域色条，背景 `rgba(255,255,255,.08)`。底部显示数据源状态（飞书 / 能耗：live 或 mock）。 |
| **Topbar** | 高 56px，白底，带下边框。左侧是页面标题和面包屑；右侧依次是上次同步时间、「立即同步」按钮（同步中显示旋转图标并禁用，完成后用 toast 报告新增、更新、删除条数）、退出登录。 |
| **KpiCard** | label（caption，ink-2）→ value（kpi）+ 单位（body，ink-3）→ 可选 delta（带 ↑↓，颜色由「上升是否为好事」决定）→ 可选 sparkline（灰色，最后一点用强调色）。可点击的卡片 hover 时描边变为 brand。 |
| **Card** | 白底，1px 描边，圆角 14px，阴影 card。头部高 48px，放标题（h2）、副标题（caption）和右侧操作区。 |
| **Badge / StatusBadge** | 高 20px，圆角 6px，micro 字号。结构为「圆点 + 文字」，浅底加深色文字。`OverdueBadge`：红「超时 3 天」、黄「临期」。 |
| **FilterBar** | 一行排列，位于内容上方，左对齐。顺序：时间预设 → 楼栋 → 工种 → 渠道 → 关键词 → 开关。有筛选生效时显示「重置」按钮。 |
| **Segmented** | 灰底容器，选中项白底加阴影，用于视图切换、时间预设。 |
| **DataTable** | 表头 bg-subtle、sticky；行高 40px；数字右对齐并用 tabular-nums；行悬停 bg-hover；可点击行打开抽屉。空状态为插画位、一行说明和操作按钮。 |
| **KanbanColumn / TicketCard** | 列底 bg-subtle，列头显示「状态名 + 计数 + 红黄计数」。卡片白底，左侧 3px 超时色条（红 / 黄 / 无）。卡片第一行是楼栋楼层 chip 和工种；第二行是两行截断的描述；底部是渠道和挂单时长。 |
| **BuildingTile** | 平面拓扑中的楼块，底色按健康度着色（good 白、warn 浅黄、bad 浅红），角标显示未完成工单数。选中时描边变为 brand，并加 2px 外环。 |
| **Drawer** | 从右侧滑出，宽 520px，带遮罩。Esc 关闭，打开后焦点进入抽屉。头部固定，内容区可滚动。 |
| **Toast** | 位于右下角，3.5 秒后消失，分成功 / 失败 / 信息三种。 |
| **Skeleton** | 首次加载时显示 `--bg-subtle` 脉冲块；重新取数时保留旧内容，降低透明度（`opacity .55`）。 |

## 4. 可访问性

- 所有交互元素可用键盘操作，焦点环为 `2px solid --brand` 并带 2px offset。
- 状态不只用颜色表达，一律配图标或文字。
- 图表提供「查看数据」表格视图；楼栋拓扑图中每个楼块都是 `button`，`aria-label` 包含楼栋名和指标。
