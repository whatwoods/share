# 湾谷运营工作台 · 设计系统 v2（极简精致）

> 方向：Linear / Notion 式极简控制台。**白底，用细线分隔，不用卡片堆叠；配色只有黑白灰加一个强调色；靠排版本身建立层级**。
> 使用场景：以电脑为主，手机偶尔查看。三项核心任务：**催办超时工单、发现能耗异常、给领导汇报**。
> 落地文件：`web/src/styles/index.css`（tokens）、`web/src/components/ui/*`（组件）。

## 1. 原则

1. **先结论，后数据**。首页第一行是一句话，例如「今天有 20 单超时报修、12 项高危遗留……需要跟进」，打开页面就知道今天该做什么。
2. **颜色只用于状态和数据**。界面框架只有黑白灰；红色表示超时或高危，黄色表示临期或异常，紫色表示争议或高危遗留，绿色表示已完成。强调色 `#5e6ad2` 用于图表和选中态。
3. **不用卡片，用细线和留白**。区块之间用 `Section` 组件（标题加一条 1px 细线）分隔；列表采用一行一条的形式（Linear issue 风格）。
4. **操作就近**。催办文本、对账摘要都能一键复制；按 `⌘K` 或 `/` 可全局搜索；导出按钮放在对应列表旁边。
5. **数字是主角**。指标值统一用 `tabular-nums` 等宽数字，字号 32/56px、字重 500，字距 -0.02em。

| 黄 / 临期、异常 | `--color-warn` | `#f0a429` |

**字号**：正文 14、辅助 13/12、区块标题 15/600、页面标题 26/600、指标 32/500、汇报主数字 56–72/500。

## 3. 组件

| 组件 | 说明 |
|---|---|
| `TopBar` | 高 56px，半透明白底，下方 1px 细线。从左到右依次为：Logo、文字导航（今日 / 楼宇 / 能耗 / 维修 / 遗留攻坚）、⌘K 搜索框，以及同步、汇报模式、退出三个图标按钮。 |
| `Stat` / `StatRow` | 不带卡片的指标块：「状态点 + 标签 → 大数字 + 单位 → 说明」。多个指标之间用竖向细线分隔，可点击跳转。 |
| `Section` | 结构为「标题 + 计数 → 描述 → 右侧操作区」，下方 1px 细线，内容直接铺在白底上。 |
| `TicketRow` / `LegacyRow` | 一行一条记录，从左到右依次为：状态点、位置、描述、工种或状态、时长。悬停时整行背景变灰，行与行之间用 1px 细线隔开。 |
| `Tabs` | 下划线式标签页，带计数，用于切换页内视图。 |
| `Segmented` | 灰底分段控件，用于时间范围、排序等次要切换。 |
| `Select`（筛选） | 未选时显示为描边文字按钮；选中后变成「标签 值 ×」的强调色浅底样式，点 × 可直接清除。 |
| `Drawer` | 右侧浮起的圆角面板，宽 560px。内容依次为：元信息、标题、属性列表、备注原文、操作（复制催办）。 |
| `CommandPalette` | `⌘K` 或 `/` 呼出，按页面、楼栋、日常工单、施工遗留分组展示结果，支持键盘上下选择、回车打开。 |
| `ParkMap` | 白色楼块配极淡底色。「问题分布」模式下，用红点（超时）和紫点（高危遗留）加数字标注问题；「用电强度」模式用强调色单色阶表示电量高低。 |

## 4. 图表

- 单系列统一用强调色 `#5e6ad2`；对比用的基线用 `#d6d6d6`；热力图用强调色单色阶（8 级）。
- 线宽 2px，柱宽不超过 24px，柱端 4px 圆角，网格线 `#f2f2f2`，坐标轴文字 `#8f8f8f`、11px。
- 每个图表都有 hover tooltip，数值在前、名称在后；有两个及以上系列时显示图例。
